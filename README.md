# PersonalMediaLibrary - Личная медиатека

## Описание выполненной работы
Разработано WPF-приложение "PersonalMediaLibrary" для авторизации и регистрации пользователей в системе личной медиатеки.

**Реализованный функционал:**
- Страница авторизации (логин/пароль)
- Страница регистрации (ФИО, Email, пароль, подтверждение пароля)
- Проверка совпадения паролей при регистрации
- Фирменный стиль в тёмной теме
- Централизованное управление стилями в App.xaml

**Цветовая схема (Вариант 7):**
- Фон: `#FF212121` (тёмно-серый)
- Акцентный цвет: `#FFFF5722` (оранжевый, как кнопка play)
- Дополнительный цвет: `#FF00B0FF` (яркий голубой)
- Шрифт: Roboto
